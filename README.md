# YeaHub Questions

Учебный проект — клиент для работы с публичной базой вопросов YeaHub.
Список вопросов с фильтрами и пагинацией, страница детального просмотра вопроса.

## Стек

- React
- React Router
- Axios
- Vite
- CSS Modules

## Запуск проекта

1. Установить зависимости:

   ```bash
   npm install

   ```

2. Создать файл .env на основе образца:

   ```bash
     cp .env.example .env

   ```

   ```cmd
     copy .env.example .env

   ```

3. Запустить dev-сервер:

   ```bash
     npm run dev
   ```
